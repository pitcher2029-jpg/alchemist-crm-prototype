# Alchemist CRM — прототип

Концепт современной замены учёта заявок и продаж на Google Таблицах + GAS.
Один файл `index.html`: без сервера и сборки, данные встроены в страницу.

**Открыть:** скачайте `index.html` и откройте в браузере (или через GitHub Pages, если он включён).

## Разделы

- **Обзор** — KPI за период (выручка, чеки, средний чек, доля абонементов, клиенты, минуты), выручка по месяцам, филиалы, сотрудники, топ услуг, воронка новых клиентов.
- **Новая продажа** — форма с поиском клиента и подсказками из прайса.
- **Отчёт смены** — итоги смены и последние отчёты.
- **Журнал** — все продажи с фильтрами по филиалу, категории и сотруднику.
- **Клиенты** — сегменты, сортировка по сумме покупок, визитам и последнему визиту, карточка с историей.
- **Мотивация** — черновой расчёт начислений специалистам по настройкам листа ST, пороги можно менять.
- **Прайс** — справочник услуг.
- **Качество данных** — услуги в продажах, которых нет в прайсе, и другие расхождения.

Переключатель «Кто работает» в шапке: «Руководитель» видит всё, вход как специалист показывает его данные.
Новые продажи сохраняются в `localStorage` браузера; сброс — в окне «О прототипе».

## Данные

Структура и объёмы взяты из реальной таблицы, но **все персональные данные обезличены**:

- имена клиентов и сотрудников заменены вымышленными (детерминированно, без совпадений с реальными);
- комментарии к продажам удалены;
- фамилии в названиях услуг заменены на `***`;
- учётные данные и телефоны в сборку не попадают;
- все денежные суммы (продажи, прайс, планы, пороги мотивации) умножены на один скрытый коэффициент.

Даты, количества, услуги и пропорции сохранены, поэтому отчёты и графики выглядят как настоящие, но абсолютные суммы вымышленные.

## Ограничения прототипа

- Нет сервера и общей базы: каждый браузер видит свои изменения.
- Расчёт мотивации — упрощённый (сумма бонусов по правилам из настроек).
- Это демонстрация интерфейса и логики, а не готовая к работе система.
